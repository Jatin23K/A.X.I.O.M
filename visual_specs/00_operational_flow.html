A.X.I.O.M — 00 Complete Operational Flow

End-to-End Request Pipeline: HTTP Request to Grounded Response
30-Second Elevator Pitch: Every user query passes through 11 sequential stages, each with a strict latency budget, security checkpoint, or quality gate. The pipeline is designed to serve Cache Hits in under 15ms, Text RAG in under 600ms, and Multimodal Video RAG in under 2.5 seconds — with zero hallucinations guaranteed by the RAG Triad Observability layer.

Full Pipeline Diagram

HTTP REQUEST (Headers: Bearer JWT | Body: Query + Modality)
  │
  ▼
[ 1. API GATEWAY: JWT AUTHENTICATION (<0.5ms) ] → (Invalid Token) → REJECT 401
  │ Decodes JWT → Extracts Tenant_ID, Department, Clearance_Level
  │ Computes Permission_Hash = SHA256(Tenant + Dept + Clearance)
  ▼
[ 2. INPUT GUARDRAILS (<5ms) ] → (Malicious/PII) → REJECT 400
  │ Sanitizes query, strips PII, blocks prompt injection
  ▼
[ 3. ROLE-SCOPED CACHE CHECK (<15ms) ] → CACHE HIT → RETURN INSTANTLY
  │ Key: SHA256(Tenant + Dept + Clearance + Query)
  │ Checks L1 Redis Exact Hash → L2 Redis Vector Similarity (>=0.92)
  ▼ CACHE MISS
[ 4. QDRANT PRE-FILTERING ] 
  │ Filters: rbac_roles CONTAINS user_role AND required_clearance <= user_clearance
  │         AND is_active_version == true AND department_id == user_department
  ▼
[ 5. MODALITY ROUTER ]
  ├──► TEXT → Matryoshka 1536d Embedding → BM25+HNSW RRF → Cross-Encoder
  ├──► IMAGE → ColPali ViT Patches → MaxSim Late Interaction
  ├──► AUDIO → WhisperX STT + CLAP → Dual-Vector Search
  └──► VIDEO → PySceneDetect Keyframes + WhisperX + CLAP → 3-Stream Search
  ▼
[ 6. DEPARTMENT MODEL ROUTER ]
  ├──► HR/Support → Gemini 2.5 Flash-Lite (<300ms, $0.0001/query)
  ├──► Engineering → Gemini 2.5 Flash (<800ms, $0.001/query)
  └──► Legal/Finance → Gemini 2.5 Pro (<2500ms, $0.02/query)
  ▼
[ 7. LLM/VLM GENERATION ]
  │ Context Budget: 8,000 token cap per standard query
  │ API Circuit Breaker: HTTP 429 → Key Rotation → Flash Fallback → Ollama
  ▼
[ 8. OUTPUT GUARDRAILS ]
  │ Groundedness Score < 1.0 → SAFE FAILURE: Block response, return citation gap
  │ Verbatim Citation Mapping: [Ref X] → Exact PDF page / Audio timestamp / Video frame
  ▼
[ 9. RAG TRIAD SCORING (Async Non-Blocking) ]
  │ Context Relevance + Groundedness + Answer Relevance → logged to Telemetry
  │ OpenTelemetry trace_id spans entire pipeline
  ▼
[ 10. CACHE WRITE ]
  │ Stores response in Redis under Role-Scoped Key with 24h TTL
  │ Tags: cacheable=true/false per document sensitivity
  ▼
[ 11. SERVE RESPONSE TO USER ]
     Answer + [Ref X] Citations + Source Document Links + Timestamps

Safe Failure Decision Points

Every point in the pipeline where A.X.I.O.M. exits gracefully instead of hallucinating:

  • Context Relevance < 0.40 → Block LLM call, return knowledge gap message
  • Groundedness < 1.00 → Strip unbacked claims, return partial answer with citation gap warning
  • Circuit Breaker OPEN → Route to fallback model, never return 500 error
  • JWT Invalid/Expired → Return 401, never expose any cached data
