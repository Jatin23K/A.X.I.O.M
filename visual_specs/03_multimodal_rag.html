A.X.I.O.M — 03 Multi-Modal RAG Engine

ColPali Visual RAG · Dual-Path Audio RAG · 3-Stream Video RAG

Section 0: 30-Second Pitch

A.X.I.O.M. handles 4 data modalities — Text, Image, Audio, and Video — each with a dedicated ingestion strategy, vector schema, and retrieval algorithm. Text uses Matryoshka 2-vector hybrid search (see Module 02). Images use ColPali ViT spatial patch multi-vector matrices with MaxSim Late Interaction — eliminating the need for a Cross-Encoder Reranker. Audio uses a Dual-Path pipeline combining WhisperX speech transcription with CLAP acoustic fingerprinting. Video uses a 3-Stream synchronized temporal pipeline. All 4 modalities are stored in a single Qdrant database using Named Vector Fields.

Section 2: Image RAG — ColPali Patch-Based Multi-Vector Retrieval

Building Phase
  • Zero OCR / Zero Text Parsing. Each PDF page is rendered as a raw 1024×1024 RGB image tensor.
  • Vision Transformer (ViT / PaliGemma) splits each page into a 32×32 grid = 1,024 spatial patches.
  • Each patch is assigned its own embedding vector. One page = Multi-Vector Matrix of 1,024 patch vectors.
  • Stored in Qdrant as a ColBERT-style multi-vector payload.
Retrieval Phase (MaxSim Late Interaction)
  • User query is tokenized into query token vectors.
  • For each query token, find the Maximum Cosine Similarity patch on each page.
  • Page Score formula: Score = Σ(q∈Q) max(p∈P) (v_q · v_p)
  • Returns Top-N highest scoring pages to VLM.
Why No Re-Ranker is Needed
  • MaxSim already performs fine-grained token-to-patch cross-attention in a single pass.
  • Adding a Cross-Encoder would duplicate the precision gain for 1.5-2.0 seconds extra latency.
Why No Text Normalization
  • Text preprocessing (lowercasing, stopwords, stemming) operates on parsed text strings.
  • ColPali never parses text — it operates on raw pixel tensors.
  • Only L2 Unit Normalization (||v||₂ = 1.0) is applied to patch vectors to enable SIMD dot-product acceleration.
Image Cache (in 01_cache_architecture.html)
  • Tier 0: pHash Hamming Distance ≤ 4 (exact/near-duplicate images)
  • Tier 1: CLIP/SigLIP 512d vector cache in Redis RAM

Section 3: Audio RAG — Dual-Path Ingestion

The Dual-Path Architecture 
RAW AUDIO FILE (.wav / .mp3)
  │
  ├──► PATH A: SEMANTIC (SPEECH)
  │    • WhisperX STT → Word-level timestamped transcript
  │    • Text Embedding → V_speech vector
  │    • VAD Silence Chunking: 10s-45s windows
  │
  └──► PATH B: ACOUSTIC (SOUND)
       • CLAP Mel-Spectrogram → V_acoustic 512d vector
       • Chromaprint acoustic fingerprint (Tier 0 Cache)
       • 10s sliding window chunks
Unified Qdrant Payload 
{
  "audio_id": "AUD_1042",
  "start_time": "02:15",
  "end_time": "02:45",
  "transcript": "Replace valve 4 immediately",
  "vectors": {
    "speech_vec": [0.88, 0.05, ...],
    "acoustic_vec": [0.12, -0.44, ...]
  }
}
VAD Chunking Strategy
  • Minimum chunk: 10 seconds
  • Maximum chunk: 45 seconds
  • Split trigger: Natural silence > 0.5 seconds (Voice Activity Detection)
  • Overlap: 2-second overlap prevents cutting mid-sentence

Section 4: Video RAG — 3-Stream Synchronized Temporal Pipeline

Architecture 
RAW VIDEO FILE (.mp4)
  │
  ├──► 1. VISUAL STREAM
  │    • PySceneDetect / OpenCV scene-cut detection
  │    • 1 Keyframe extracted per scene change
  │    • CLIP/SigLIP → V_visual vector
  │    • Screen OCR for text on screen
  │
  ├──► 2. SPEECH STREAM
  │    • WhisperX → word-level timestamps
  │    • Text Embedding → V_speech vector
  │
  └──► 3. ACOUSTIC STREAM
       • CLAP → V_acoustic vector
       • 10s Mel-Spectrogram chunks
Temporal Window Synchronization
  • All 3 vectors are bound to a shared 10-second temporal window: {start: '04:12', end: '04:22'}
  • Retrieval returns the keyframe image + transcript text + exact clickable timestamp
Video Chunking (Why Scene-Cut over Fixed Windows)
  • A 2-hour 1080p video = 216,000 raw frames at 30FPS
  • Fixed 1FPS sampling = 7,200 vectors (wasteful)
  • Scene-Cut Detection compresses to ~150 keyframe vectors (97.9% compression)
  • Each vector represents a complete visual context (not a random mid-sentence frame)
Multi-Scale Hierarchical Chunking for Long Videos
  • Low Level: 10-second clip vectors (for precise timestamp pinpointing)
  • High Level: 3-5 minute chapter vectors (for macro topic search)
Retrieval Scoring (3-Stream RRF)

Score = w1·Sim(Q, V_visual) + w2·Sim(Q, V_speech) + w3·Sim(Q, V_acoustic)
