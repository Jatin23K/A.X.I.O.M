A.X.I.O.M — 07 Circuit Breakers, SLAs & Department Model Routing

API Key Pool Rotation · Stateful Circuit Breaker · Latency/Cost SLAs · Department Intelligence Tiers
30-Second Pitch: Enterprise RAG systems must never crash when a cloud LLM provider returns HTTP 429 rate limits or HTTP 503 outages. A.X.I.O.M. uses a Stateful Circuit Breaker with a 6-key API pool, automatic Round-Robin rotation, and a 3-state machine (CLOSED → OPEN → HALF-OPEN) that reroutes traffic to lightweight fallback models within 0.1ms of detecting a failure — without the user ever seeing an error. The Latency/Cost SLA layer intelligently routes queries to the cheapest model capable of answering the question, using Department-Level Model Routing (Flash-Lite for HR FAQ, Flash for Engineering, Pro for Legal/Finance reasoning) to balance intelligence, latency, and API billing costs.

The 6-Key API Pool + Round-Robin Rotation

Incoming LLM Requests
        │
        ▼
[ ROUND-ROBIN KEY SELECTOR ]
  Key 1 → Key 2 → Key 3 → Key 4 → Key 5 → Key 6 → Key 1...
        │
  Each key serves ~16.7% of total request volume
  HTTP 429 on Key 3 → Key 3 removed from pool for 60s
  Remaining keys (1,2,4,5,6) absorb load at ~20% each

Why Round-Robin over Random Selection

  • Even distribution prevents single-key exhaustion under burst traffic
  • Stateful tracking per key: request_count, last_error_time, consecutive_failures
  • Keys are re-admitted after 60-second cooldown window

Circuit Breaker State Machine

┌────────────────────────────────────────────────────────────┐
│                                                            │
│  ┌──────────────┐  Error Rate>50%   ┌──────────────────┐  │
│  │ CLOSED STATE │ ─────────────────► │   OPEN STATE     │  │
│  │ (Normal Ops) │ ◄───────────────── │ (Bypass Primary) │  │
│  └──────────────┘  Success Rate>95%  └────────┬─────────┘  │
│         ▲                                     │            │
│         │           60s Cooldown              │            │
│         │      ┌─────────────────────┐        │            │
│         └──────│  HALF-OPEN STATE    │◄───────┘            │
│                │ (1 Trial Request)   │                     │
│                └─────────────────────┘                     │
└────────────────────────────────────────────────────────────┘
  • CLOSED (Normal): Routes to primary model (Gemini 2.5 Pro/Flash)
  • OPEN (Tripped): 5 consecutive failures OR HTTP 429 OR >2000ms timeout → Bypass primary for 60s → Route ALL traffic to fallback
  • HALF-OPEN (Recovery): After 60s cooldown, send 1 trial request → Success → CLOSED | Failure → OPEN again

Fallback Cascade

Primary (Gemini Pro) → Flash (Gemini 2.5 Flash) → Flash-Lite (Gemini 2.5 Flash-Lite) → Local (Ollama/Llama-3-8B)

Context Token Budget (Cost SLA Enforcement)

  • Standard queries: Max 8,000 tokens of context window
  • If RRF retrieves 40 chunks (50,000 tokens): Reranker trims to Top-5 (~4,000 tokens)
  • Legal/Finance queries: Extended budget to 32,000 tokens (Pro model context window)
  • Token budget prevents single queries from consuming disproportionate API billing

Three Real-World Circuit Breaker Examples

Example 1: HTTP 429 Key Rotation

Monday 9AM surge exhausts Key 1 quota → Circuit Breaker detects HTTP 429 → Removes Key 1 from pool in 0.1ms → Rotates to Key 2 → User experiences zero delay

Example 2: Regional Cloud Outage Failover

Gemini API responds in >2000ms due to GCP regional incident → Circuit Breaker trips to OPEN after 5 timeouts → ALL traffic routed to Ollama/Llama-3-8B local inference → Users receive answers in 2.4s instead of 30s timeout

Example 3: Oversized Context Cost Spike Prevention

User submits 200-page document asking for summary → RAG retrieves 60 chunks (80,000 tokens) → Cost SLA enforces 8,000 token cap → Reranker trims to Top-5 highest-scored chunks (4,200 tokens) → Query costs $0.002 instead of $0.08
