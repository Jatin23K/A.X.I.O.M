RETRIEVAL — How Things Are Retrieved (The Read Side Sequence)

The complete 11-stage synchronous query execution path from HTTP Request to Grounded Citation Response

⚡ Synchronous Retrieval Execution Flow & Security Checkpoints
Every request passes through strict latency budgets, 2-Checkpoint security, Role-Scoped Caching, and Output Groundedness checks.

Checkpoint 1: API Gateway
Validates JWT signature & expiration in <0.5ms. Blocks unauthorized routes before touching backend.
Role-Scoped Cache Keys
Key = SHA256(Tenant + Dept + Clearance + Query). Ensures Lower Roles can NEVER hit Higher Role caches.
Checkpoint 2: Pre-Filtering
Filters Qdrant payload BEFORE vector distance math. Guarantees 100% of retrieved chunks are authorized.
Safe Failure Contract
If Context Relevance < 0.40, the LLM refuses gracefully instead of hallucinating fake answers.

The out-of-band write architecture that processes heavy files, updates indices, and invalidates stale caches without blocking live user queries.

CQRS Architecture
Write side runs asynchronously in Celery background queues. Ingesting 4-hour videos never slows live user queries.
Soft-Delete Versioning
v1 vectors marked is_active_version = false. Enables 1-second rollbacks & historical audit queries.
Department Retention Map
HR soft-deletes old policies. Legal/Engineering maintains multi-version coexistence for contracts & API docs.
Cache Pattern Invalidation
Updating a document flushes matching Redis keys (DEL CACHE:*:DOC_ID:*), guaranteeing zero stale responses.
