Design Philosophy

ColPali over OCR+Text

Preserves the spatial layout of visual documents, ensuring tables, charts, and diagrams are understood exactly as they appear visually.

Pre-Filtering over Post-Filtering

Prevents security breaches at the vector search level by aggressively filtering data before similarity search is applied.

Hierarchical Cache Keys

Using Hierarchical Cache Keys over Role-Only Keys eliminates cache duplication while maintaining strict security boundaries.

Department Model Routing

Using Department Model Routing over a Single Model balances intelligence, latency, and cost per business unit optimally.
